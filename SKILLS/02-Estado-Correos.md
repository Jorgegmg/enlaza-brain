# Estado Correos + Tareas Pendientes

## Objetivo
Resume diario de tu bandeja para arrancar jornada sin scroll infinito.

## Inputs
- Integración: Microsoft 365 (Outlook)
- Filtros: Correos sin leer, tareas vencidas, seguimientos

## Outputs
- Resumen ejecutivo (texto + tabla)
- Distribución: Chat interno (mostrar en Cowork)
- Secciones:
  - Urgentes (vencidas, sin respuesta >2 días)
  - Tareas asignadas a ti sin cerrar
  - Threads con tu equipo que requieren tu input
  - Resumen por remitente (cuántos, desde cuándo)

## Criterios de éxito
- ✓ Máx 2 minutos de lectura
- ✓ Priorizado por: urgencia, remitente, fecha
- ✓ No mostrar spam ni newsletters
- ✓ Incluir links directos a Outlook para responder

## Configuración
- Horario: 09:00 (lunes-viernes)
- Frecuencia: Diaria
- Solo correos último 24h
