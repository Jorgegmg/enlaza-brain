# Criterios de Calidad - Operativa

## Estándar de servicio
- Albaranes sin errores: >99%
- Trazabilidad completa: 100%
- Atención cliente: <2h respuesta
- Documentación: CMR + albaran + prueba entrega

## Incidencias
- Crítica (cliente perdido): escalada CEO inmediato
- Alta (cliente enfadado): escalada Ops + CEO 24h
- Media (cliente notifica): respuesta <4h
- Baja (log interno): registro y análisis semanal
